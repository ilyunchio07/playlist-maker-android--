Playlist Maker (Учебный проект)

Мобильное приложение для поиска, хранения и прослушивания музыкальных треков (учебная эмуляция функционала медиатеки). Проект разработан в рамках курса "Android-разработчик" от Яндекс.Практикума.

Статус проекта

Параметр | Значение
--- | ---
Текущая версия | v7.0
Статус | Завершено внедрение архитектурного ядра (Data и Domain).
Стек UI | Jetpack Compose (100%)

Архитектура

Проект построен на принципах Clean Architecture (Чистая Архитектура), что обеспечивает независимость бизнес-логики от внешних фреймворков и источников данных.

Слой | Назначение
--- | ---
UI (Presentation) | Отображение интерфейса (Jetpack Compose) и управление жизненным циклом.
Domain | Содержит чистые Domain-модели (Track), интерфейсы репозитория и бизнес-правила.
Data | Реализует контракты Domain, работает с эмулятором сервера (Storage) и выполняет маппинг DTO → Domain-модель.

Приложение использует подход Single Activity Architecture с навигацией на основе Compose Navigation (NavHost).

Технологический стек

- Язык: Kotlin
- Фреймворк UI: Jetpack Compose
- Навигация: Compose Navigation
- Сборка: Gradle
- Контроль версий: Git/GitHub

Реализованный функционал

К завершению 7-го спринта в приложении реализовано:

1. Три экрана: Главный экран, Экран Поиска, Экран Настроек.
2. Навигация: Плавные переходы между экранами с помощью NavHost.
3. Вёрстка: Pixel-perfect дизайн строки поиска (высота 36dp) и элементов списка настроек, полностью соответствующий макетам Figma.
4. Взаимодействие с ОС: Реализованы Intents для кнопок "Поделиться", "Написать в поддержку" и "Пользовательское соглашение".
5. Data Flow: Выстроена полная цепочка получения данных через Repository, Client и Mock-хранилище.
