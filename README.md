# Проект Playlist Maker
Мобильное приложение для поиска и сохранения музыкальных треков с плейлистами и избранным. Реализовано на Jetpack Compose в стиле MVVM; данные берутся из iTunes Search API, локальное хранилище построено на Room и DataStore.

## Возможности приложения
- Поиск треков в iTunes с дебаунсом и отображением состояний загрузки/ошибок/пустого результата.
- История поисковых запросов (до 10 записей, DataStore), быстрая подстановка по тапу.
- Экран деталей трека: обложка 512x512, метаданные, добавление в избранное, добавление в плейлист через нижний лист.
- Избранное: список треков из локальной базы Room, удаление по долгому тапу.
- Плейлисты: создание с обложкой из галереи, названием и описанием; отображение сеткой; удаление плейлистов; добавление треков в существующие плейлисты из деталей трека.
- Настройки: шаринг ссылки на приложение, письмо в поддержку, открытие пользовательского соглашения.

## Общая информация
- Стек: Kotlin, Jetpack Compose (Material 3), Navigation Compose, Coroutines + StateFlow, Retrofit2 + Gson (iTunes API), Room, DataStore, Coil.
- Архитектура: MVVM, разделение data/domain/presentation, Single Activity c навигацией через NavHost; зависимости пробрасываются через `Creator`.
- Версия приложения: 1.0; minSdk 29, targetSdk 36.
- Запуск: открыть проект в Android Studio, синхронизировать Gradle, запустить на устройстве/эмуляторе с Android 10+.

## Вкладка настройки
- Поделиться ссылкой на приложение через системный шаринг.
- Написать в поддержку (Intent с почтой и шаблоном письма).
- Открыть пользовательское соглашение в браузере.

![Экран настроек](task/экран_настроек.png)

## Вкладка избранное
- Список треков из локальной базы Room; пустое состояние при отсутствии треков.
- Переход в детали трека по тапу, удаление из избранного по долгому нажатию.

![Экран избранного](task/экран_избранные_треки.png)

## Вкладка плей-лист
- Экран создания плейлиста: выбор обложки через системный пикер (сохранение в приватное хранилище), обязательное имя, опциональное описание.
- Экран списка плейлистов: сетка с превью, счетчиком треков, удаление по долгому нажатию с подтверждением.
- Экран плейлиста: обложка, название, описание, счетчик треков, список добавленных треков; удаление плейлиста.

![Экран нового плейлиста](task/экран_новый_плейлист.png)
![Экран плейлистов](task/экран_плейлисты.png)

## Вкладка поиск
- Экран поиска: поле ввода с debounce 2 c, отображение истории при фокусе, состояния загрузки/пусто/ошибка, список результатов.
- Экран деталей трека: отображение обложки и метаданных, добавление/удаление из избранного, добавление в выбранный плейлист через нижний лист.
