🎵 Playlist Maker

Мобильное приложение для поиска, хранения и прослушивания музыкальных треков (эмуляция функционала медиатеки). Проект разработан в рамках курса Android-разработчик от Яндекс.Практикума.

⭐️ Статус проекта

Параметр Значение Текущая версия v8.0 Статус Полностью реализован функционал поиска на основе архитектуры MVVM и StateFlow. Стек UI Jetpack Compose (100%)

🏗️ Архитектура

Проект построен на принципах Clean Architecture (Чистая Архитектура), что обеспечивает независимость бизнес-логики от внешних фреймворков и источников данных.

Слой Назначение UI (Presentation) Отображение интерфейса (Jetpack Compose). Использует ViewModel и StateFlow для управления состояниями. Domain Содержит чистые Domain-модели (Track), интерфейсы репозитория и бизнес-правила. Data Реализует контракты Domain, работает с эмулятором сервера (Storage) и выполняет маппинг DTO - Domain-модель.

Приложение использует подход Single Activity Architecture с навигацией на основе Compose Navigation (NavHost).

💻 Технологический стек

Язык: Kotlin Фреймворк UI: Jetpack Compose Паттерн: MVVM Навигация: Compose Navigation Сборка: Gradle Контроль версий: Git/GitHub

📋 Реализованный функционал

К завершению 8-го спринта в приложении реализовано:

Три экрана: Главный экран, Экран Поиска, Экран Настроек.

MVVM и Поиск: Реализована полная цепочка поиска данных: ViewModel управляет состояниями (Loading, Content, Error), которые отображаются на экране. Поиск работает корректно по названию трека ИЛИ по артисту.

Вёрстка: Pixel-perfect дизайн строки поиска (36dp) и элементов списка настроек, полностью соответствующий макетам Figma.

Навигация: Плавные переходы между экранами с помощью NavHost.

Взаимодействие с ОС: Реализованы Intents для кнопок "Поделиться", "Написать в поддержку" и "Пользовательское соглашение".
